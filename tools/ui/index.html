Sizer

This is the runnable UI shell for the Sizer product. It intentionally does not perform sizing in the browser: future forms and visualizations should call the /v1 API so the engine remains the single source of truth.

Wizard & expert formsProgressive trade-entry flows will collect canonical sizing requests.
Constraint stackA waterfall chart will highlight the binding layer from the API response.
DiagnosticsWarnings, drawdown paths, and scenario comparisons will render from engine output.
